# AccessLab — demo

Demo educativa de Alan Berra Garcia. Tres lecciones, cuestionarios, contraste y auditoría axe-core local. Sin cuentas, backend ni envío de datos. El progreso se conserva solo en el navegador; los respaldos son archivos locales.

Los ejemplos defectuosos son intencionales y aislados. La auditoría parcial no certifica WCAG; faltan lectores de pantalla, usuarios reales y dispositivos físicos. axe-core conserva su licencia en vendor/AXE-LICENSE.txt. Fuente principal privada.
